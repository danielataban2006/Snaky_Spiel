##Spiel Snaky

#Eine einfache Terminal-Implementierung des Spiels "Snaky" in Java 

Auf einem 20*40 Feld befinden sich eine Tür (T) , ein Goldstück (G) , eine Schlange (S) und ein Spieler (P) . 
Der Spieler versucht das Gold einzusammeln bevor er durch die Tür gehen kann, um von der Schlange zu entkommen.
Durch Eingabe im Terminal kann man die Spielerposition nach rechts (r), links (l), oben (f), unten (b) verändern.

##Ziel ist von der Schlange nicht gefressen zu werden und die Tür mit dem Goldstück zu erreichen.
